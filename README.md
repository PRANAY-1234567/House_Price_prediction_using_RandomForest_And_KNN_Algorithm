# 🏠 House Price Prediction Using Machine Learning

## 📌 Project Overview

House Price Prediction is a Machine Learning project that predicts the estimated price of a house based on different features such as the number of bedrooms, bathrooms, living area, location, and other property-related factors.

The project uses supervised machine learning algorithms to analyse historical housing data, identify patterns, and predict house prices.

It demonstrates the complete machine learning workflow, including data preprocessing, exploratory data analysis, feature engineering, model training, evaluation, and price prediction.

## 🎯 Objectives

- Predict house prices using machine learning algorithms.
- Analyse factors that influence property prices.
- Clean and preprocess housing datasets.
- Train and evaluate different regression models.
- Understand the practical applications of machine learning.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Libraries:**

## 📊 Dataset Description

The dataset contains historical housing information used to train the machine learning model.

Some of the features may include:

| Feature | Description |
|---|---|
| Bedrooms | Number of bedrooms |
| Bathrooms | Number of bathrooms |
| Square Feet | Total area of the house |
| Location | Location of the property |
| Floors | Number of floors |
| Year Built | Construction year |
| Price | Actual house price (Target Variable) |

*Note: Actual dataset columns may differ depending on the dataset used.*

## ⚙️ Machine Learning Algorithms

The project can use the following supervised learning algorithms:

1. **Linear Regression:** Predicts house prices by identifying relationships between input features and prices.
2. **Decision Tree Regressor:** Predicts prices using decision-based rules.
3. **Random Forest Regressor:** Combines multiple decision trees to improve prediction performance.

## 🔄 Project Workflow

1. Import required Python libraries.
2. Load the housing dataset.
3. Perform data cleaning and preprocessing.
4. Handle missing values and duplicate records.
5. Perform Exploratory Data Analysis (EDA).
6. Select relevant features for prediction.
7. Split the dataset into training and testing sets.
8. Train machine learning models.
9. Evaluate model performance.
10. Predict house prices using new input data.

## 📈 Model Evaluation

The model's performance can be evaluated using the following metrics:

- **Mean Absolute Error (MAE):** Measures the average absolute difference between actual and predicted prices.
- **Mean Squared Error (MSE):** Measures the average squared prediction error.
- **R² Score:** Measures how well the model explains variations in house prices.
